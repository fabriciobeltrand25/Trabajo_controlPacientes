# 🚀 Guía de Configuración y Colaboración

¡Bienvenido al proyecto! Sigue estos pasos para clonar el repositorio usando Eclipse o GitHub Desktop, vincular el proyecto y realizar tus primeros cambios.

---

## 📥 Opción 1: Clonar directamente desde Eclipse

1. Abre Eclipse y ve a **File** ➡️ **Import...**
2. Selecciona **Git** ➡️ **Projects from Git** y presiona **Next**.
3. Elige **Clone URI** y presiona **Next**.
4. En el campo **URI**, pega el enlace del repositorio:
   ```text
   https://github.com/fabriciobeltrand25/Trabajo_controlPacientes.git
   ```
5. Presiona **Next**, selecciona la rama principal y avanza.
6. Elige la carpeta local donde se guardará el proyecto, presiona **Next** y luego **Finish**.
7. ¡Listo! El proyecto aparecerá en tu Package Explorer de Eclipse.

---

## 🛠️ Opción 2: Clonar con GitHub Desktop (Recomendado)

### Paso 1: Clonar el repositorio
1. Abre GitHub Desktop y ve a **File** ➡️ **Clone repository...**
2. Selecciona la pestaña **URL** y pega el enlace del repositorio:
   ```text
   https://github.com/fabriciobeltrand25/Trabajo_controlPacientes.git
   ```
3. Elige la ruta de tu computadora donde quieres guardarlo y haz clic en **Clone**.

### Paso 2: Importar la carpeta en Eclipse
1. En GitHub Desktop, haz clic derecho sobre el nombre del repositorio (`Trabajo_controlPacientes`) en el panel izquierdo.
2. Selecciona **Show in Explorer** (o Finder) para ver la ubicación exacta de la carpeta.
3. Abre Eclipse, ve a **File** ➡️ **Import...**
4. Selecciona **General** ➡️ **Existing Projects into Workspace** y presiona **Next**.
5. En **Select root directory**, busca y selecciona la carpeta que te mostró GitHub Desktop.
6. Marca la casilla del proyecto, haz clic en **Finish** y listo.

---

## 💻 Cómo hacer tu primer cambio (Prueba)

1. En Eclipse, abre el archivo `Pacientes.java` y agrega un comentario de prueba. Guardar los cambios (`Ctrl + S`).
2. Abre **GitHub Desktop**. Verás que en la esquina izquierda aparece el archivo modificado.
3. **Buenas prácticas (Antes de subir):** Presiona el botón **Fetch origin** (o **Pull**) arriba para asegurarte de tener la versión más reciente de tus compañeros.
4. En la esquina inferior izquierda de GitHub Desktop, escribe un **Título** corto y una **Descripción** sobre tu cambio en los cuadros de texto.
5. Haz clic en el botón azul **Commit to main** (o el nombre de la rama).
6. Finalmente, haz clic en el botón **Push origin** en la barra superior para subir tus cambios a GitHub.
